🛠️ What I build

I like single-file, offline-first HTML tools that an analyst can open in a browser with no install. Some examples:

Analyst toolkits: encode/decode pipelines in the style of CyberChef, URL and domain list cleaners, typosquat generators
OSINT helpers: search-query builders for brand-abuse discovery, plus WHOIS/RDAP and DNS lookups
Evidence tools: screenshot annotation, and QR decoding that defangs and flags suspicious URLs
Detection concepts: scanners that check for conditional content delivery on phishing and malvertising URLs, and leak monitoring
